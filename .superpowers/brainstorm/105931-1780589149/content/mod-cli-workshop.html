设计要点

  • Agent 颜色：gemini=cyan(#22d3ee), claude=orange(#fb923c), mcp/validation=purple(#c084fc), aider=green(#4ade80)
  • 状态指示灯：实心=运行中，空心=空闲，闪烁=阻断/等待
  • 阻断行高亮：claude-code 被安全闸阻断时，整行带橙色背景
  • PID 列：PID 粗体，内存值用 agent 颜色标记
  • 点击行：dispatch sandbox:node-selected 事件，高亮选中行
  • 无配置按钮：CLI 工坊只展示运行中进程，配置在 Agent 能力面板
