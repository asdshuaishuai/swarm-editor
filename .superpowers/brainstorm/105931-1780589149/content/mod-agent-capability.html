设计要点

  • 状态颜色：executing=orange(#f0883e), thinking=blue(#58a6ff), idle=green(#3fb950), offline=gray(#6b7280)
  • 配置按钮：齿轮图标在每个卡片右上角，点击打开 AgentConfigModal
  • 能力标签：彩色 chip 显示 agent 的 capabilities
  • 活跃工具：橙色 chip 显示当前正在调用的工具名
  • Handoff 箭头：显示最近的 agent 间交互方向
  • Filter tabs：全部/活跃/空闲/告警，右上角显示计数
  • 告警图标：红色三角感叹号，出现在有 alert 或 state=error 的 agent 上
