交互说明

  • Provider 类别 Tab：第一方/第三方切换，过滤预设列表
  • Provider 预设卡片：点击选择，自动填充 Base URL 和推荐模型。选中态蓝色边框 + 实心圆
  • 模型配置：结构化输入框，Model/API Key/Base URL + 高级模型（Sonnet/Haiku/Opus）
  • API Key 脱敏：默认显示 tp-se6y••••，点击"显示"切换明文
  • Raw JSON：Monaco Editor 编辑 permissions/plugins 等非结构化配置
  • 格式校验：实时校验，通过显示绿色勾，失败显示红色叉 + 错误信息
  • 保存：校验通过才写入原生文件，校验失败不破坏 agent 可用性
  • 文件路径：底部显示实际写入的配置文件路径
