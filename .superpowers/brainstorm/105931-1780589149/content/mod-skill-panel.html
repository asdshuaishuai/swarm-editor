设计要点

  • 来源标签：FS=文件系统(蓝), AGENT=Agent能力(紫), PROJ=项目(绿)
  • 范围标签：global / project / agent 名称
  • Agent pills：彩色=已启用，灰色=未启用，点击切换
  • 搜索过滤：实时搜索技能名称和描述
  • Filter tabs：全部/文件系统/Agent/项目，按来源过滤
  • 独立面板：从 MCP 面板拆分出来，作为左侧边栏的独立 tab 或子区域
