B: 卡片式

每个 MCP 服务器一张卡片。开关 toggle 做成 iOS 风格滑块，agent pills 和配置按钮在卡片内。视觉更丰富，但信息密度低。

关键功能：每个 MCP 独立开关、per-agent 启用/禁用、配置按钮（打开单个 MCP 的配置 modal）。
