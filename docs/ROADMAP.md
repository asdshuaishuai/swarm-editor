# Swarm Editor 开发路线图

> 最后更新: 2026-05-17 | 当前版本: R5933 | 连续通过: 715 轮

---

## 项目定位

**多 Agent 协调编辑器** — 对标 Cursor / Claude Code / Windsurf，独有多 Agent 协调、涌现智能、共识机制。

---

## 已完成阶段

### Phase 1: 基础架构 (2026-03) ✅

- Monaco 编辑器集成
- WebSocket 通信层
- 文件系统操作 (CRUD)
- Git 集成 (17 个命令)
- 终端面板 (xterm.js)
- 基础 UI 框架

### Phase 2: Agent 核心 (2026-04) ✅

- ACP 协议实现 (JSON-RPC 2.0 over stdio)
- Agent 注册表与生命周期管理
- Session 管理 (创建/发送/关闭)
- Swarm 协调器
- Team 管理
- 共识机制 (Queen Bee)

### Phase 3: 编辑器能力 (2026-04) ✅

- LSP 桥接 (32 个命令，多语言支持)
- 代码库索引 (`@Codebase`)
- `@Files` 语法支持
- Diff 视图
- 多标签编辑
- 快捷键系统

### Phase 4: Agent 深度集成 (2026-05) ✅

- ACP Agent 自动扫描 (10 个已知 CLI)
- MCP 服务器发现与管理
- Skill 扫描 (文件系统 + Agent 能力 + MCP 工具)
- Agent 配置面板
- Scanner 面板 (3 Tab: Agents/MCP/Skills)
- Agent 响应内容回传
- MCP 工具浏览与调用 UI

---

## 当前阶段

### Phase 5: 内联智能 (2026-05 进行中)

**目标**: 补齐与 Cursor/Windsurf 的核心差距 — 内联补全

| 任务 | 优先级 | 状态 |
|------|--------|------|
| 内联补全 (Tab completion) | P1 | 待开发 |
| Ghost Text 预览 | P1 | 待开发 |
| 多行补全 | P2 | 待开发 |
| 补全接受/拒绝快捷键 | P1 | 待开发 |
| 补全触发策略 (延迟/字符) | P2 | 待开发 |

**技术方案**:
- 复用 LSP `textDocument/completion` 已有桥接
- Monaco `InlineCompletionsProvider` 接口
- Agent 会话上下文作为补全信号源
- 去抖策略: 300ms 延迟 + 最少 2 字符触发
