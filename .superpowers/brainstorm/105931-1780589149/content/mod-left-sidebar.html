设计要点

  • Tab 栏：3 个 tab（项目文件 & Git / MCP 与技能 / Agent 能力），选中态蓝色上边框
  • 文件树：语言标签色块（TS=蓝, GO=青, MK=灰），Git 状态标记（M=修改, A=新增）
  • 当前文件高亮：蓝色背景 + 蓝色文件名
  • 符号大纲：LSP SymbolKind 标签（C=类/蓝, M=方法/紫, F=函数/黄, I=接口/青）
  • 搜索过滤：输入框实时过滤符号树
  • 行号：符号右侧灰色行号，点击跳转到编辑器对应行
  • 上下分割：文件树占上半部分，符号大纲占下半部分，中间分割线
