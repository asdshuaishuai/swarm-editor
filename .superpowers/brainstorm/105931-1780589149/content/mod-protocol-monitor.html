交互说明

  • LIVE/OFF 开关：控制是否实时接收协议包，OFF 时暂停滚动
  • 统计圆点：ACP(黄)、A2A(青)、MCP(紫) 各类型计数
  • 过滤 Tab：全部/ACP/A2A，指令模式下隐藏 MCP tab
  • 视图切换：列表 ↔ 时间轴，时间轴显示包的时间分布
  • 包卡片：每种类型有独立颜色编码和图标，背景色按类型着色
  • 指令模式 vs 完整模式：指令模式下 MCP 包只显示一行简化记录
  • 上下文过滤：点击沙盘节点后，自动过滤该 agent 相关的协议包
  • 搜索：全文搜索包的所有字段（type/source/target/payload/details）
