设计要点

  • 扫描来源：显示每个 Agent 的配置文件路径和发现数量，绿点=已扫描，橙点=无结果
  • 服务器列表：checkbox 多选，显示名称 + 命令/URL + 来源 Agent 标签
  • 全选/反选：顶部 checkbox 控制
  • 计数：底部显示已选数量
  • 触发方式：MCP 面板顶部的"导入"按钮
  • 去重：同名服务器合并来源标签
