**问题**: 无法在对话中引用特定文件

**竞品方案**:
- Cursor: `@Files path/to/file.go` 语法
- Claude Code: 自然语言文件引用

**建议实现**:
```typescript
// 前端：在 AgentPanel 中解析 @Files 语法
const parseFileReferences = (text: string) => {
  const matches = text.match(/@Files?\s+([^\s]+)/g);
  return matches?.map(m => m.replace(/@Files?\s+/, '')) || [];
};
```
