# Pi 0.83 Core Capability Review

Swarm Editor vendors `earendil-works/pi` tag `v0.83.0` and keeps its own JSONL stdio tool-broker patch. The upgrade is not a CLI adapter expansion: Pi remains the sole agent runtime, while the Compose UI and Kotlin services communicate in-process.

## Capabilities Adopted Now

- **Provider termination evidence:** Pi now preserves normalized `stopReason` plus provider-specific `rawStopReason`. The Kotlin RPC layer records both in the Agent activity trail so truncation, provider rejection, cancellation, and ordinary completion remain distinguishable.
- **Safer RPC execution:** upstream fixes ensure RPC bash follows the user-bash path, concurrent bash cancellation is reliable, active session replacement aborts cleanly, and failed Git package installs do not poison retries.
- **Frozen model catalog:** the model JSON shipped by `@earendil-works/pi-ai@0.83.0` is vendored and built with `build:offline`. Clean builds no longer depend on a live `models.dev` request or rewrite generated provider sources.
- **Broader model semantics:** pending and raw provider stop reasons, refreshed model metadata, improved llama.cpp usage accounting, Qwen token-plan thinking controls, and newer Copilot model support flow through the existing Pi runtime.

## High-Value Follow-Up

1. Use Pi's scoped model registry as the capability set from which the primary Agent assigns models to dynamically created sub-Agents.
2. Convert Swarm verification scenarios into Pi eval cases with typed outputs and invariant checks instead of relying only on free-form reviewer prompts.
3. Map Pi AgentHarness branch-scoped tool state and session events onto the Swarm dependency graph so retries resume from verified graph state.
4. Evaluate the new SQLite session storage only as a local persistence backend; do not introduce Pi Server or remote transport into normal desktop communication.

## Explicit Non-Goals

- Do not expose `auth print-api-key` or bearer-token export through the UI.
- Do not adopt Pi Server, HTTP, WebSocket, OCI, or Podman for the desktop runtime.
- Do not bypass the Kotlin tool broker, Bubblewrap policy, audit records, or WASM capability boundary.

Upstream baseline: `earendil-works/pi` `v0.83.0`, commit `845d6ff1f6643aba440341cce877ce1c43ebbc39`.
